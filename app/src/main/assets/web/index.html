Phím tắt & trợ giúp

  • Space: Phát/Tạm dừng nhạc
  • ← / →: Tua lùi/tiến 5 giây · ↑ / ↓: Âm lượng
  • N / P: Bài tiếp / bài trước · M: Tắt/bật tiếng web
  • [ / ]: Chuyển tab · T: Đổi kiểu xem video (lưới/danh sách)
  • Q: Mở hàng đợi · /: Tìm bài · Esc: Đóng bảng
  • ?: Hiện bảng trợ giúp này
  • Trên điện thoại: vuốt ngang để đổi tab, vuốt trên thanh mini để next/prev, nhấn giữ một bài để mở menu tác vụ
  • Tab Nhạc: tìm, lọc, nhóm theo nghệ sĩ/album, sắp xếp; nút ⋯ trên mỗi bài để phát tiếp/thêm hàng đợi/cast/xoá
  • Tab Video: danh sách video dạng kết quả tìm kiếm, phát trên web/điện thoại/cast, điều khiển trình phát (tua, tốc độ, PiP, toàn màn hình)
